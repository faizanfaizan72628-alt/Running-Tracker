# 🏃 Running Tracker
A beginner-friendly Running Tracker web application built with HTML, CSS, and JavaScript.
## 🚀 Features
- 🏃 Start Running
- ⏸ Pause/Stop Running
- 🔄 Reset Run
- ⏱️ Automatic Running Timer
- 👟 Steps Counter
- 📍 Distance Calculator
- 🚀 Speed Calculator
- 🎯 5 KM Daily Goal
- 📊 Progress Bar
- 📱 Responsive Design
## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
